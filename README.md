# 사무실 펫 (OfficePet)

업무시간에 바탕화면에서 같이 지내는 다마고치형 도트 펫.

## 설치

- `OfficePet-Setup-버전.exe` 실행 → 관리자 권한 없이 사용자 폴더에 설치, 바탕화면·시작 메뉴에 "사무실 펫" 바로가기 생성
- 처음 실행 시 "Windows의 PC 보호" 경고가 뜨면 `추가 정보` → `실행` (코드 서명이 없어서 뜨는 경고)

## 조작

- 왼쪽 클릭: 쓰다듬기
- 우클릭 또는 ≡ 버튼: 메뉴 (상태 / 할 일 / 집중 / 도감 / 설정)
- 끌기: 원하는 위치로 옮기기 (걷기 모드에서는 놓으면 바닥으로 떨어짐)
- 숨기기: `Esc` (펫 선택 상태) 또는 `Ctrl+Alt+P` (어디서든) — 다시 누르면 보임
- 작업표시줄 트레이 아이콘: 보이기/숨기기, 걷기/앉기 전환, 위치 초기화, 자동 실행, 업데이트 확인, 종료

## 게임 규칙

- 시간은 평일 9~18시에만 흐름 (주말·퇴근 후·`오늘 휴무` 켠 날은 멈춤)
- 성장: 알(2일) → 아기(2일) → 어린이(3일) → 어른
- 부화 분기 (알 단계 돌봄 방식)
  - 밥주기가 절반 이상 → 떡이
  - 메뉴보다 클릭(쓰다듬기)을 더 많이 → 두부 사원
  - 골고루 → 새싹이
  - 8번 미만 → 먼지뭉치
- 배부름·기분이 20 미만이면 성장 속도 절반
- 할 일 완료, 뽀모도로 집중 완료 시 기분 상승
- 어른이 되면 도감에 ★ 등록, 새 알을 받아 다른 아이 키우기 가능
- 설정 → 빠른 모드: 테스트용 (실제 1초 = 근무 5분, 근무시간 제한 해제)

## 저장 위치

- `%APPDATA%\OfficePet\save.json`
- 프로그램과 분리되어 있어서 업데이트·재설치해도 유지됨
- PC별로 따로 저장됨 (다른 PC로 옮기려면 이 파일을 복사)

## 밸런스 조정

- `renderer/game.js` 맨 위 `CFG` 값 수정 (근무시간, 단계별 기간, 감소 속도, 뽀모도로 시간, 걷는 속도)

## 자동 업데이트 배포 방법

설치된 프로그램은 켜질 때(이후 6시간마다) GitHub Releases에 새 버전이 있는지 확인하고, 있으면 내려받아 다음 실행 때 적용함.

### 처음 한 번

1. GitHub에 **공개(Public)** 저장소 `office-pet` 생성 (계정: `Dhoon-CNU`)
   - 비공개 저장소는 프로그램에 접근 토큰을 넣어야 해서 비추천
   - 계정이나 저장소 이름을 바꾸면 `package.json`의 `build.publish` 부분도 같이 수정
2. 이 폴더 전체를 저장소에 올리기 (`node_modules`, `dist` 제외 — `.gitignore`에 설정됨)

### 업데이트할 때마다

1. 코드 수정
2. `package.json`의 `version` 올리기 (예: 0.2.0 → 0.2.1) — 버전이 같으면 업데이트로 인식 안 됨
3. 빌드: `npm install` (처음 한 번) → `npm run dist`
   - 윈도우 PC에서 하려면 Node.js 설치 필요
4. GitHub 저장소 → Releases → `Draft a new release`
   - 태그: `v0.2.1` (버전 앞에 v)
   - `dist` 폴더의 파일 3개 첨부: `OfficePet-Setup-0.2.1.exe`, `OfficePet-Setup-0.2.1.exe.blockmap`, `latest.yml`
   - `Publish release`
5. 각 PC의 펫이 알아서 받아서 "새 버전 준비 완료" 말풍선 → 다음 실행 때 적용

## 폴더 구조

- `main.js` — 프로그램 창, 트레이, 단축키, 저장, 자동 업데이트
- `preload.js` — 화면과 프로그램 사이 연결
- `renderer/sprites.js` — 도트 캐릭터
- `renderer/game.js` — 게임 로직, 메뉴
- `renderer/index.html`, `renderer/style.css` — 화면
- `build/icon.png` — 아이콘
